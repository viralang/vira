# Vira Programming Language - VS Code & Cursor Extension

Official Visual Studio Code and Cursor extension for the **Vira Programming Language**.

## Features

- **Syntax Highlighting:** Full TextMate grammar for all Vira keywords (`actor`, `arena`, `tensor`, `pub:`, `mut:`, `@`, `<-`).
- **Language Configuration:** Automatic bracket matching, indent rules, and comment toggling (`//`).
- **LSP Integration:** Diagnostics, error reporting, hover tooltips, and on-save formatting via `vira lsp`.

## Getting Started

1. Open any `.vir` source file.
2. The language mode will automatically switch to **Vex**.
3. Format with `Shift+Alt+F` or run `vira fmt` from the integrated terminal.
