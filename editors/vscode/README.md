# Vex Programming Language - VS Code & Cursor Extension

Official Visual Studio Code and Cursor extension for the **Vex Programming Language**.

## Features

- **Syntax Highlighting:** Full TextMate grammar for all Vex keywords (`actor`, `arena`, `tensor`, `pub:`, `mut:`, `@`, `<-`).
- **Language Configuration:** Automatic bracket matching, indent rules, and comment toggling (`//`).
- **LSP Integration:** Diagnostics, error reporting, hover tooltips, and on-save formatting via `vex lsp`.

## Getting Started

1. Open any `.vex` source file.
2. The language mode will automatically switch to **Vex**.
3. Format with `Shift+Alt+F` or run `vex fmt` from the integrated terminal.
